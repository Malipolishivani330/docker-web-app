# Docker Web Application

## Project Description

This project demonstrates containerization of a simple web application using Docker and Nginx.

The application is built using HTML, packaged into a Docker image, and deployed as a Docker container.

## Technologies Used

- Docker
- Docker Compose
- Nginx
- HTML

## Architecture

Source Code → Dockerfile → Docker Image → Docker Container → Nginx → Web Application
